# beomstar_git

프로젝트 저장소입니다.

## 소개

이 저장소는 실제 프로젝트 개발을 위한 공간입니다.
아래에 프로젝트가 무엇인지, 어떻게 실행하는지 채워 나갑니다.

## 폴더 구조

```
beomstar_git/
├── README.md          # 프로젝트 설명서 (지금 이 파일)
├── english-teacher/   # Emma - AI 영어 선생님 (HTML 앱)
├── chinese-teacher/   # 니하오 중국어 - 왕초보 기초 회화 앱 (HTML 앱)
└── spanish-teacher/   # 올라 스페인어 - 왕초보 기초 회화 앱 (HTML 앱)
```

## 시작하기

각 폴더의 `index.html` 파일을 브라우저(크롬/엣지/사파리 권장)에서 열면 바로 실행됩니다.
별도의 설치나 서버가 필요 없습니다.

### 니하오 중국어 (chinese-teacher)

처음 배우는 사람을 위한 중국어 기초 회화 앱입니다.

- **커리큘럼**: 발음(성조·병음) → 인사 → 숫자·시간 → 자기소개 → 일상 회화 → 실전 여행 회화, 총 6단계 29레슨
- **레슨 구성**: 단어 → 핵심 문장 → 회화 → 문법 → 확인 퀴즈 (70% 이상 통과 시 다음 레슨 열림)
- **발음 듣기**: 브라우저 내장 중국어 음성(TTS)으로 원어민 발음 듣기, 느리게 듣기 지원
- **성조 훈련소**: 성조 도표와 듣고 맞히기 게임
- **복습함(SRS)**: 통과한 레슨의 단어를 간격 반복 방식으로 자동 복습
- **진도 저장 · 이어보기**: 완료한 레슨은 물론 **레슨 중간에 멈춘 단계까지 저장**되어, 다시 열면 그 자리에서 이어집니다
- **진도 백업 · 기기 이동**: 설정에서 백업 코드를 만들어 다른 기기(폰↔PC)에 붙여넣으면 진도가 그대로 옮겨집니다

### 올라 스페인어 (spanish-teacher)

처음 배우는 사람을 위한 스페인어 기초 회화 앱입니다. 디자인은 스페인 국기 색(빨강·황금)을 사용했습니다.

- **커리큘럼**: 발음(알파벳·강세) → 인사 → 숫자·시간 → 자기소개 → 일상 회화 → 실전 여행 회화, 총 6단계 29레슨
- **레슨 구성**: 단어 → 핵심 문장 → 회화 → 문법 → 확인 퀴즈 (70% 이상 통과 시 다음 레슨 열림)
- **발음 듣기**: 브라우저 내장 스페인어 음성(TTS)으로 원어민 발음 듣기, 느리게 듣기, 한글 독음 표기
- **동사 변화 훈련소**: 규칙/불규칙 동사 변화표와 맞히기 게임, r/rr 등 발음 비교 듣기
- **복습함(SRS)**: 통과한 레슨의 단어를 간격 반복 방식으로 자동 복습
- **진도 저장 · 이어보기**: 완료한 레슨은 물론 **레슨 중간에 멈춘 단계까지 저장**되어, 다시 열면 그 자리에서 이어집니다
- **진도 백업 · 기기 이동**: 설정에서 백업 코드를 만들어 다른 기기(폰↔PC)에 붙여넣으면 진도가 그대로 옮겨집니다
