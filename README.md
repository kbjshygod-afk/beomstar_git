# beomstar_git

프로젝트 저장소입니다.

## 소개

이 저장소는 실제 프로젝트 개발을 위한 공간입니다.
아래에 프로젝트가 무엇인지, 어떻게 실행하는지 채워 나갑니다.

## 폴더 구조

```
beomstar_git/
├── README.md          # 프로젝트 설명서 (지금 이 파일)
├── english-teacher/   # Emma - AI 영어 선생님 (HTML 앱)
├── chinese-teacher/   # 니하오 중국어 - 왕초보 기초 회화 앱 (HTML 앱)
└── daily-english-quest/  # Daily English Quest - 하루 15분 영어 회화 게임 (HTML 앱)
```

## 시작하기

각 폴더의 `index.html` 파일을 브라우저(크롬/엣지/사파리 권장)에서 열면 바로 실행됩니다.
별도의 설치나 서버가 필요 없습니다.

### 니하오 중국어 (chinese-teacher)

처음 배우는 사람을 위한 중국어 기초 회화 앱입니다.

- **커리큘럼**: 발음(성조·병음) → 인사 → 숫자·시간 → 자기소개 → 일상 회화 → 실전 여행 회화, 총 6단계 29레슨
- **레슨 구성**: 단어 → 핵심 문장 → 회화 → 문법 → 확인 퀴즈 (70% 이상 통과 시 다음 레슨 열림)
- **발음 듣기**: 브라우저 내장 중국어 음성(TTS)으로 원어민 발음 듣기, 느리게 듣기 지원
- **성조 훈련소**: 성조 도표와 듣고 맞히기 게임
- **복습함(SRS)**: 통과한 레슨의 단어를 간격 반복 방식으로 자동 복습
- **진도 저장**: 브라우저(localStorage)에 자동 저장, 연속 학습 기록

### Daily English Quest (daily-english-quest)

영어 초급자가 하루 15분씩 듣기와 따라 말하기를 게임처럼 이어가는 앱입니다.

- **하루 4단계**: Blind Listening(10XP) → Read & Listen(10XP) → Repeat Practice(15XP) → Boss Mission(20XP), 하루 최대 55XP
- **30일 콘텐츠**: 주제 중복 없이 3개 챕터로 구성
  - Chapter 1 (Day 1-10) 매일의 생활: 출근 준비, 커피, 장보기, 배달, 지하철, 약국, 고객센터, 은행, 요리, 빨래
  - Chapter 2 (Day 11-20) 밖에서: 택시, 식당, 길 묻기, 미용실, 헬스장, 공항, 호텔, 옷 쇼핑, 우체국, 영화관
  - Chapter 3 (Day 21-30) 사람과 대화: 새 동료, 날씨 스몰토크, 약속 잡기, 가족, 사과, 도움 요청, 주말 이야기, 병원, 환불, 작별
- **게임 요소**: 누적 XP, Lv.1~Lv.5, 연속 학습일(Streak), 스테이지 상태, 오늘 완료율
- **듣기**: 브라우저 내장 음성(Web Speech API)으로 스크립트·문장을 느린 속도로 읽어 줌
- **말하기 채점**: 마이크로 문장을 말하면 단어 단위로 비교해 점수를 매기고, 보스 문장은 70% 이상이면 클리어 (미지원 브라우저는 버튼으로 클리어)
- **저장**: 브라우저(localStorage)에 자동 저장, XP 중복 지급 방지
- **백업·복원**: 기록을 JSON 파일이나 백업 코드로 내보내고 다시 불러오기 (기기 이동, 브라우저 데이터 삭제 대비)
- **모바일 우선**: iPhone Safari 등 모바일에서 한 손으로 쓰기 좋은 다크 RPG 스타일 UI
