# 🌍 랭귀지 스타터 — 왕초보 외국어 회화 (무료)

영어·중국어·일본어·스페인어·프랑스어를 하루 10분씩. 설치·가입 없이 휴대폰 브라우저에서 바로 시작해요.

👉 **바로 쓰기: https://kbjshygod-afk.github.io/beomstar_git/language-teacher/**
(언어를 정해서 보내려면 뒤에 `?lang=en` · `zh` · `ja` · `es` · `fr`)

## 이렇게 시작해요
1. 링크를 열어요. 카카오톡에서 열었다면 화면의 **기본 브라우저로 열기**를 눌러 주세요(소리·마이크·로그인이 잘 돼요).
2. 배울 언어를 고르고, 하루 목표와 시작 위치를 정해요.
3. 🔊 듣고 🎤 따라 말하며 한 레슨씩(약 15분). 퀴즈를 통과하면 다음 레슨이 열려요.

## 알아 두세요
- 기록은 기본적으로 **이 기기의 이 브라우저**에만 저장돼요. ⚙️ 설정에서 **구글로 로그인**하면 휴대폰·PC 어디서든 이어져요(로그인 기능은 [설정 안내](docs/cloud-setup.md)대로 켜야 나타나요).
- 로그인 없이 옮기려면 ⚙️ 설정 → 📦 백업 코드/파일 → 새 기기 첫 화면의 **다른 기기 기록 가져오기**.
- 앱 안 **❓ 도움말**에 소리·마이크·기록 옮기기·홈 화면 추가 방법이 있어요.
- [개인정보 안내](privacy.html) · 문의·오류 제보는 [GitHub 이슈 페이지](https://github.com/kbjshygod-afk/beomstar_git/issues)로 알려 주세요(공개 게시판이라 개인정보는 적지 마세요).

## 예전 앱을 쓰던 분
「니하오 중국어」「올라 스페인어」「Daily English Quest」「Emma 영어 선생님」은 랭귀지 스타터로 합쳐졌어요. 옛 주소는 안내 페이지이고, 니하오 중국어·올라 스페인어·Daily English Quest는 **같은 브라우저라면 예전 기록이 자동으로 옮겨져요**. Emma의 퀴즈 기록은 옮겨지지 않고 `english-teacher/emma.html`에 그대로 있어요(Emma의 퀴즈·AI 자유 회화는 그곳에 고급 사용자용으로 남아 있어요).

## 개발자용

### 폴더 구조
```
beomstar_git/
├── index.html            # 첫 화면(랭귀지 스타터 소개 + 언어 바로 가기)
├── privacy.html          # 개인정보 안내
├── 404.html              # 없는 주소 안내(비슷한 주소는 자동 이동)
├── assets/og-image.png   # 링크 미리보기 이미지(1200x630)
├── language-teacher/     # 랭귀지 스타터 본체(단일 HTML) + data-XX.js · stories-XX.js
│   ├── cloud-config.js   # Firebase 웹 설정(null이면 로그인·통계·의견 기능 숨김)
│   ├── manifest.webmanifest, icons/   # 홈 화면 설치
│   └── vendor/firebase/  # 직접 묶은 Firebase SDK(필요할 때만 불러옴)
├── tools/firebase/       # SDK 묶기 스크립트(build.mjs — FB_VER도 자동으로 적음) · Firestore 보안 규칙(firestore.rules)
├── docs/cloud-setup.md   # 구글 로그인·클라우드 저장 켜는 방법(주인용)
├── daily-english-quest/  # 옛 주소 → 헬로 영어 안내(DEQ 기록 가져오기)
├── chinese-teacher/      # 옛 주소 → 니하오 중국어 안내(nihao_zh_v1 기록 자동 이관)
├── spanish-teacher/      # 옛 주소 → 올라 스페인어 안내(hola_es_v1 기록 자동 이관)
└── english-teacher/      # 옛 주소 → 헬로 영어 안내, emma.html(예전 Emma)
```
정적 파일뿐이라 GitHub Pages에 그대로 올리면 됩니다. 로컬에서는 `python3 -m http.server`로 띄운 뒤 **http://localhost:8000/language-teacher/** 로 열면 로그인까지 시험할 수 있어요. Firebase의 승인된 도메인에 기본으로 들어 있는 것은 `localhost`라서, `127.0.0.1`로 열면 로그인이 막혀요(file://로도 로그인 외 기능은 동작).

### 배포 전 체크
- `data-*.js`·`stories-*.js`를 고쳤다면 `node tools/stamp-data-ver.mjs`로 `DATA_VER`(내용 해시)를 갱신하세요(`--check`로 확인만). 잊어도 서비스 워커가 뒤에서 확인해 다음 열 때 새 데이터로 바뀝니다.
- Firebase 묶음(`language-teacher/vendor/firebase/`)은 `tools/firebase`에서 `npm install && npm run build`로만 만드세요. 빌드가 `FB_VER`(묶음 내용 해시)를 자동으로 적어요. 확인만: `node tools/firebase/build.mjs --check`. SDK 버전 올리기는 [설정 안내](docs/cloud-setup.md)의 ‘자주 묻는 것’ 참고.
- 서비스 워커 캐시 이름: 데이터 캐시(`lt-data`)는 바꾸지 마세요(바꾸면 모든 언어의 오프라인 자료가 사라져요). 화면 쪽을 비워야 할 때만 `SHELL`(`lt-shell-vN`)의 번호를 올리세요.
- `sw.js`를 바꿔 배포하면, 열어 둔 화면(홈 화면 앱 포함)에 ‘🆕 새 버전이 나왔어요 · 누르면 새로고침’ 안내가 떠요. `index.html`만 바꾼 배포는 다음에 열 때 바로 새 화면이 됩니다.
- 저장 형식(store 칸)을 바꾸면 `index.html`의 `SCHEMA`를 올리세요. 옛 화면은 더 새 형식의 기록을 덮어쓰지 않고 새로고침을 권합니다.
- 서비스 워커(`language-teacher/sw.js`)에 문제가 생기면 `tools/sw-killswitch.js`를 `language-teacher/sw.js`로 복사해 배포하세요. 모든 사용자의 캐시를 지우고 서비스 워커를 해제합니다.
- 문의 링크: `language-teacher/cloud-config.js`의 `SITE_CONTACT`에 구글 설문지·오픈채팅 주소를 넣으면 허브·설정·도움말·개인정보 안내에 한꺼번에 나타나요.

### 기능 한눈에 (language-teacher)

영어·중국어·일본어·스페인어·프랑스어를 **언어 선택 화면 하나로 통합**한 앱입니다. 처음 열면 🗽 영어 / 🐼 중국어 / 🎏 일본어 / 💃 스페인어 / 🥐 프랑스어 중 배울 언어를 고르고, 헤더의 🔀 언어 버튼으로 언제든 바꿀 수 있습니다. 언어마다 진도가 따로 저장됩니다.

- **커리큘럼**: 중국어·일본어·스페인어·프랑스어는 6단계 29레슨. 영어는 9단계 59레슨(0~5단계 왕초보 29레슨 + 실전 ①~③ 30일 생활 회화 = 옛 Daily English Quest)
- **레슨 흐름**: (워밍업 3문제) → 단어(4개씩 묶음, 뜻 가리기) → 핵심 문장(🎤 따라 말하기) → 회화(먼저 가리고 듣기 → "무슨 상황?" → 대본 확인, 🎭 역할극) → 문법(✋ 한 탭 확인) → 퀴즈(틀린 문제는 같은 회차 끝에 한 번 더) → 🔥 보스 미션(뜻만 보고 말하기)
- **말하기 채점**: 브라우저 음성 인식으로 "알아듣기 점수"를 매김. 영어·스페인어·프랑스어는 단어 단위, 중국어·일본어는 글자 단위(일본어 한자 인식은 스스로 확인). 음성 인식이 안 되는 브라우저·오프라인에서는 녹음해서 원어민 소리와 비교
- **좋은 목소리 자동 선택**: 기기 음성을 점수로 골라 쓰고(광둥어·장난감 음성 제외), 대화는 화자마다 다른 목소리·쉼으로 읽음. 속도 3단계
- **게임 요소**: XP·레벨 12단계, 하루 목표 링, 날짜별로 바뀌는 오늘의 퀘스트 3개, 전 언어 통합 🔥 연속 학습과 🛡️ 방패(7일마다 1개, 빠진 날을 지켜 줌), 배지 17종, 효과음·콤보·축하 연출, ⚡ 바쁜 날 1분 모드
- **복습**: 간격 반복(1·2·4·7·15·30·60일, 졸업 후에도 유지 점검), 단어 카드 + 문장 카드, 익숙한 카드는 뜻을 보고 말하기, 3단계 채점(몰랐어요/헷갈렸어요/기억했어요)·다시 잡기, 📝 오답 노트, 🧩 짝 맞추기(듣고 짝 맞추기 포함), 한 번에 20장·5장 미니 세션
- **언어별 훈련소**: 🗽 영어 👂 소리 훈련소(R/L·F/P·V/B·TH/S·장단모음 최소대립쌍, 연음·축약) · 🐼 중국어 🎵 성조 · 🎏 일본어 あ 가나 도장 · 💃 스페인어 🔠 동사 변화 · 🥐 프랑스어 🔤 발음 도장
- **쉬운 읽기(다독)**: 다섯 언어 모두 같은 줄거리의 동화 12편(숲속의 인사~미운 오리 새끼), 배운 단어만 사용, 이해도 퀴즈
- **처음부터 / 조금 알아요**: 첫 방문 때 하루 목표와 시작 위치를 고름. 영어는 30일 생활 회화부터 시작 가능, 다른 언어는 단계 건너뛰기 시험(80% 이상)으로 아는 단계를 넘김
- **기록**: 달력·목록, 최근 7일 리포트(지난주와 비교, 이 언어/전체 언어), 배지 선반
- **기록 지키기**: 기본은 이 브라우저에만 저장. ☁️ 구글 로그인하면 기록이 계정에 자동 저장돼 휴대폰·PC가 이어짐(여러 기기에서 한 공부는 합쳐지고, 초기화·복원은 다른 기기에도 반영). 로그인 없이도 짧은 백업 코드(gzip)·백업 파일 보내기로 기기 이동, 복원은 합치기/바꾸기 + 7일 되돌리기, 여러 탭 동시 사용 안전
- **함께 만들기**: 💬 의견 보내기(만족도+글), 📣 친구에게 추천·보스 클리어/연속/수료 자랑하기(공유 시트), 사용 통계(설정에서 끄기)
- **어디서나 열리게**: 카톡·밴드 등 앱 안 브라우저 감지 → 기본 브라우저로 한 번에 열기, 소리가 안 나는 기기 감지 → 안내·듣기 문제 글자로 풀기, 마이크 거부 시 기기별 안내·스스로 확인, 홈 화면 설치(PWA 매니페스트·아이콘), 링크 미리보기(카카오톡 og 이미지)
- **매일 알림**: 캘린더 반복 일정(.ics) 또는 Google 캘린더 링크
- **접근성**: 키보드 조작, 모달 포커스 가두기·Esc, 스크린리더 안내, 외국어 lang 표시, 글씨 크게, 움직임 줄이기 대응, 안드로이드 뒤로가기
- 테마 색은 언어별로 자동 전환(영어 #0A3161 / 중국어 #D92332 / 일본어 #BC002D / 스페인어 #C60B1E / 프랑스어 #0055A4)
- 주소 뒤에 `?lang=en` 처럼 붙이면 그 언어로 바로 열림

### Daily English Quest → 헬로 영어 통합 메모

Daily English Quest는 랭귀지 스타터의 영어 과정(「헬로 영어」)으로 합쳐졌습니다. 30일 콘텐츠는 실전 ①~③(6~8단계) 30레슨이 되었고, 보스 미션·말하기 채점·복습함·주간 리포트·매일 알림·두 목소리 대화 등 DEQ의 장점은 다섯 언어 모두에 이식했습니다.

- 옛 주소(daily-english-quest/)는 이사 안내 페이지입니다. 기록이 있으면 요약을 보여 준 뒤 헬로 영어로 이동하고, 다른 기기로 옮길 백업 파일도 받을 수 있습니다.
- **기록 자동 이관**: 같은 브라우저라면 헬로 영어를 처음 열 때 DEQ 기록(보스 클리어 Day → 레슨 완료·👑 — 2회차 중이면 30일 모두 완료, XP, 🔥 연속일, 복습 문장 카드, 학습 기록, 읽기 속도·알림 시각)을 그대로 가져옵니다. 가져오지 않기도 고를 수 있고, 나중에 설정에서 다시 가져올 수 있습니다(두 번 가져와도 중복되지 않음).
- **다른 기기**: DEQ 백업 파일이나 코드를 헬로 영어 → ⚙️ 설정 → 코드로 복원하기에 붙여넣으면 영어 진도로 합쳐집니다.
- 옛 DEQ 기록(localStorage)은 지우지 않고 그대로 둡니다.
