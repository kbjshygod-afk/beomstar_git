# 원가표 뷰어

구글 시트로 관리하는 원가표(품목별 단가/원가/판매가/마진율 등)를 비밀번호로 보호된 웹페이지에서 확인할 수 있는 아주 작은 웹앱입니다. 구글 시트를 수정하면 새로고침만으로 최신 데이터가 화면에 반영됩니다.

## 1. 이 프로젝트는 무엇인가요?

구글 시트에 있는 원가표를 "웹에 게시(CSV)" 기능으로 공개 CSV 주소를 만들고, 이 앱이 그 주소를 서버에서 읽어와 표로 보여줍니다. 데이터가 민감하므로 비밀번호를 입력해야만 표를 볼 수 있습니다.

## 2. 로컬에서 실행해보기

터미널(명령 프롬프트)에서 이 저장소를 내려받은 뒤, 아래 순서대로 진행하세요. (이 프로젝트는 저장소 안의 `cost-table-viewer` 폴더에 들어 있습니다.)

1. 프로젝트 폴더로 이동 후 패키지 설치
   ```bash
   cd cost-table-viewer
   npm install
   ```
2. 환경 변수 파일 만들기
   - `.env.local.example` 파일을 복사해서 `.env.local` 이라는 이름으로 저장하세요.
     ```bash
     cp .env.local.example .env.local
     ```
   - `.env.local` 파일을 열어 값을 채웁니다. 아직 구글 시트가 없다면 아래처럼 테스트용 값을 넣으면 됩니다.
     ```
     SHEET_CSV_URL=http://localhost:3000/sample-cost-table.csv
     APP_PASSWORD=아무비밀번호나입력
     SESSION_SECRET=아무나긴랜덤문자열입력12345
     ```
     (이 프로젝트에는 `public/sample-cost-table.csv` 라는 가짜 원가표 샘플 파일이 들어 있어서, 실제 구글 시트 없이도 위 주소로 바로 테스트할 수 있습니다.)
3. 개발 서버 실행
   ```bash
   npm run dev
   ```
4. 브라우저에서 `http://localhost:3000` 접속 후, 위에서 설정한 `APP_PASSWORD` 값으로 로그인해서 표가 잘 보이는지 확인하세요.

## 3. 구글 시트를 CSV로 게시하는 방법

실제 원가표를 연결하려면 구글 시트를 "웹에 게시" 기능으로 공개 CSV 주소를 만들어야 합니다. 아래 메뉴 경로를 그대로 따라가세요.

1. 구글 시트 열기
2. 상단 메뉴에서 **파일** 클릭
3. **공유** 클릭
4. **"웹에 게시"** 선택
5. 게시할 시트(시트 이름) 선택
6. 형식을 **"쉼표로 구분된 값(.csv)"** 으로 선택
7. **게시** 버튼 클릭
8. 화면에 나오는 링크(주소)를 복사해서 `SHEET_CSV_URL` 값으로 사용

> 주의: 이 링크를 아는 사람은 누구나 시트의 원본 데이터를 볼 수 있습니다(구글이 제공하는 "웹에 게시" 기능 자체의 특성입니다). 다만 이 웹앱 화면 자체는 별도의 비밀번호로 보호되므로, 링크를 아무에게나 공유하지 않는다면 안전하게 사용할 수 있습니다.

## 4. Vercel에 배포하기 (완전 처음이어도 괜찮아요)

1. [vercel.com](https://vercel.com) 에 가입합니다. (깃허브 계정으로 로그인 가능)
2. 로그인 후 대시보드에서 **"Add New..." → "Project"** 클릭
3. 이 저장소(repository)를 선택해서 **Import**
4. **"Configure Project"** 화면에서 **Root Directory** 항목을 반드시 `cost-table-viewer` 로 지정합니다. (이 프로젝트가 저장소 최상위가 아니라 `cost-table-viewer` 폴더 안에 있기 때문입니다. "Edit" 버튼을 눌러 폴더를 선택하세요.)
5. **Environment Variables** 항목에 아래 3개를 추가합니다.
   - `SHEET_CSV_URL` : 3단계에서 만든 실제 구글 시트 CSV 주소
   - `APP_PASSWORD` : 원하는 비밀번호
   - `SESSION_SECRET` : 아무도 모르는 임의의 긴 문자열 (예: 키보드를 아무렇게나 눌러 만든 30자 이상의 문자열)
6. **Deploy** 버튼 클릭
7. 배포가 끝나면 발급된 주소(예: `https://your-app.vercel.app`)로 접속해서 확인합니다.

## 5. 아이패드/휴대폰에서 사용하기

1. 아이폰/아이패드의 **Safari** 브라우저로 배포된 주소에 접속합니다.
2. 하단(또는 상단)의 **공유 버튼**을 누릅니다.
3. **"홈 화면에 추가"** 를 선택합니다.
4. 이제 홈 화면 아이콘을 눌러 앱처럼 바로 접속할 수 있습니다.

## 6. 데이터는 어떻게 업데이트되나요?

구글 시트 내용만 수정하면 됩니다. 이 웹앱은 매번 화면을 새로고침(또는 표 위의 **"새로고침"** 버튼 클릭)할 때마다 구글 시트의 최신 데이터를 다시 가져오므로, 시트를 수정한 뒤 다시 배포(재배포)할 필요가 전혀 없습니다.

## 7. 비밀번호를 바꾸고 싶다면?

1. Vercel 프로젝트 페이지에서 **Settings → Environment Variables** 로 이동
2. `APP_PASSWORD` 값을 원하는 새 비밀번호로 수정
3. 저장 후 **Redeploy**(재배포) 실행

---

## 참고: 환경 변수 요약

| 변수명 | 설명 |
| --- | --- |
| `SHEET_CSV_URL` | 구글 시트를 "웹에 게시"해서 얻은 공개 CSV 주소 (서버에서만 사용, 클라이언트에 노출되지 않음) |
| `APP_PASSWORD` | 웹앱 접속용 비밀번호 |
| `SESSION_SECRET` | 로그인 쿠키를 서명(위조 방지)하는 데 쓰이는 임의의 긴 문자열 |

## 기술 스택

- Next.js (App Router, JavaScript)
- papaparse (CSV 파싱)
- 별도 데이터베이스 없음 — 서명된 쿠키만으로 로그인 상태 유지 (stateless)
