# 듀오링고 분석 — 왜 잘 될 수밖에 없었나, 그리고 무엇을 옮기나

작성: 2026-11-13 · 방법: `.claude/skills/app-teardown` · 출처를 직접 읽지 못한 것은 **[요약]**으로 표시

## 1. 한 문단 요약 (대표님용)
듀오링고가 잘 되는 이유는 불꽃·XP·리그 같은 겉모양이 아니라 그 밑의 **학습 엔진**이에요. 단어마다 "지금 기억하고 있을 확률"을 계산해서
**잊기 직전에** 다시 내 주고(반감기 회귀, HLR), 학습자마다 "이 문제를 맞힐 확률"을 계산해서 **대부분은 맞히되(세션 정답률 약 92~93%)
가끔 70%짜리 도전 문제**를 섞어요(Birdbrain). 틀린 것은 **그 레슨 끝에 다시** 나오고, 같은 내용을 **알아보기 → 떠올려 쓰기 → 말하기**
순서로 점점 어렵게 반복해요. 습관 장치(연속 학습·방패·리그·알림)는 이 엔진에 사람을 매일 데려오는 역할이고, 회사는 "어제 온 사람이
오늘도 오는 비율(CURR)"을 가장 중요한 숫자로 봐요. 우리 앱은 겉모양은 대부분 갖췄지만, 엔진은 고정 간격 상자 방식이라
여기를 듀오링고 방식으로 바꾸는 것이 가장 효과가 커요.

## 3. 왜 잘 될 수밖에 없었나 (원인 → 바뀌는 행동 → 측정된 효과)
1. **잊기 직전에 꺼내 쓰게 한다(HLR)** → 아는 단어 반복은 줄고 잊어 가는 단어만 복습 → 예측 오차 절반, 하루 재방문 +12%. 연습량이 7% 줄었는데 저자들은 "금색을 유지하려는 헛연습이 줄었다"고 봤어요.
2. **대부분 맞히게, 조금만 어렵게(Birdbrain)** → 좌절하지 않고 계속 → 세션 정답률 92~93%, 정답률이 높을수록 실력도 높음.
3. **틀린 것은 그 자리에서 다시 맞히고 끝난다** → 틀린 기억이 아니라 맞힌 기억으로 끝남.
4. **알아보기 → 떠올리기 → 말하기** → 같은 내용을 점점 깊게 꺼내 씀(인출 연습) → 길로 필수화한 뒤 점수 상승.
5. **복습이 길 안에 들어 있다** → 학습자가 계획하지 않아도 간격 반복과 섞어 배우기가 일어남.
6. **작게 쪼개 매일** → 몰아서보다 나눠서 하는 학습(분산 학습) + 습관 → CURR이 성장의 최대 지렛대.
7. **실패를 덜어 주는 안전장치(방패)** → 하루 빠져도 포기하지 않음.
8. **반응 없는 사람에겐 알림을 줄인다** → 알림 피로를 막음.
9. **모든 것을 실험한다** → 작은 개선이 쌓임(우리는 못 함 — 사용자 수·서버가 없음).

## 4. 우리 앱 지금 (코드 진단, `language-teacher/index.html`)
- **복습 간격**: `SRS_INTERVALS = {1:1, 2:2, 3:4, 4:7, 5:15, 6:30, 7:60}` 고정 상자(Leitner). `grade()`(복습 화면)에서 ok면 상자 +1, 실패면 −2, 어려움이면 내일.
  카드에 저장되는 것: `box, due, rv, rt, mastered, keep` — **맞힌 수·틀린 수·마지막 시각 기록이 없음**.
- **복습 순서**: `dueCards()` — 오래 밀린 순 → 낮은 상자 순. 기억 확률 개념 없음.
- **채점**: 복습은 학습자가 "알았다/어려웠다/몰랐다"를 눌러 스스로 채점. 말하기로 맞히면 자동 ok.
- **레슨 퀴즈**: `renderQuiz()` — 레슨마다 미리 정해 둔 문항(고르기·듣기·배열·성조), 같은 유형끼리만 섞음, 70% 통과,
  틀린 문항은 끝에 한 번 더(`phase2`). **퀴즈 정답·오답이 단어 카드의 기억 기록으로 이어지지 않음.**
- **오답 노트**: `p.mistakes` — 다른 날 두 번 맞히면 졸업.
- **난이도**: 학습자 실력 추정·문항 난이도 추정 없음. 모든 학습자에게 같은 문제.
- **문제 종류**: 고르기·듣기·배열·성조. 직접 떠올려 쓰는 문제는 없고, 복습 카드에서 익숙한 단어(상자 3 이상)는 뜻 보고 말하기로 냄(`reverseCard`).

## 5. 격차 (듀오링고 / 우리 / 결과)
| 듀오링고 | 우리 | 결과 |
|---|---|---|
| 단어마다 맞힘·틀림 기록으로 반감기를 계산 | 모든 단어가 같은 고정 간격 | 쉬운 단어는 너무 자주, 어려운 단어는 너무 늦게 |

| 기억 확률이 낮은 것부터 복습 | 밀린 날짜 순 | 정작 잊어 가는 단어가 뒤로 밀림 |
| 맞힐 확률을 예측해 정답률 ~90%로 세션을 짬 | 고정 문항 | 너무 쉽거나 너무 어려운 세션 |

| 기억 강도를 레슨에 표시, 약해지면 복습 유도 | 통과한 레슨은 계속 "완료" | 잊어도 모름 |

## 6. 이식 계획 (학습 효과 ÷ 수고 순)
**1순위 — HLR 기억 모델(학습 엔진의 심장)**
- 기록: 카드마다 `hr`(맞힌 수), `hw`(틀린 수), `ht`(마지막 연습 시각, ms). 하루 같은 단어 여러 번은 한 관찰로 묶음(논문의 "세션 단위 p").
- 규칙: h = 2^(θ₀ + θᵣ·√(1+hr) + θ_w·√(1+hw)) 일, 15분~274일로 자름(논문). p = 2^(−Δ/h).
- 가중치 θ: 듀오링고 학습 데이터셋은 이 환경에서 받을 수 없어 공개되지 않은 값을 쓰지 않아요. **시작값**은 지금 상자 간격과 비슷한 반감기가 나오게
  정하고(우리 선택), 학습자 자신의 복습 결과로 **논문의 학습 규칙**(제곱 오차 + α·반감기 오차 + λ·규제, η=0.001, α=0.01, λ=0.1, AdaGrad식)대로
  기기 안에서 조금씩 맞춰요. 규제는 0이 아니라 시작값 쪽으로 당겨서, 기록이 적을 때 엉뚱한 값으로 튀지 않게 해요(우리 선택).
- 다음 복습일: p가 **0.8**로 떨어지는 날(우리 선택 — 듀오링고의 기준은 비공개, 세션 정답률을 높게 유지하려는 듀오링고 원칙에 맞춤).
- 복습 순서: p가 낮은 것부터. 복습 탭·피드 채점, 레슨 퀴즈, 맞춤 연습에서 그 단어를 맞히거나 틀린 것도 관찰로 넣음(틀리면 내일 다시).
- 기존 카드 이전: 상자 b → hr = b−1로 보고 지금 예정일은 유지(바로 쏟아지지 않게).
- 시험: 공식 값 확인, 같은 기록에서 틀림이 많을수록 반감기가 짧아짐, 퀴즈 결과가 카드에 반영됨, 이전 후 예정일 유지 — 각각 되돌리면 실패해야 함.

**2순위 — 맞춤 연습 세션(Birdbrain 축소판)**
- 기록: 언어마다 학습자 실력 θ, 단어 난이도 b(단어), 문제 유형 난이도 b(유형).
- 규칙: P(정답) = σ(θ − b_유형 − b_단어 + 기억 보정), 풀 때마다 θ += K(y−P), b −= K(y−P)/n. K는 비공개 → 0.4에서 시작해 관찰이 늘면 줄임(우리 선택).
- 세션: 10~12문제. p 낮은 단어 위주로 고르고, 문제 유형은 기억 강도에 따라 **알아보기(뜻 고르기) → 듣고 고르기 → 떠올려 쓰기/말하기**.
  예측 정답률 평균 약 0.9가 되게 고르고 **도전 문제(약 0.7) 1~2개를 끝쪽에**. 틀린 것은 세션 끝에 다시.
- 시험: 실력이 오르면 더 어려운 유형이 나옴, 틀리면 끝에 다시, 평균 예측 정답률이 목표 근처.

**3순위 — 레슨 기억 강도 표시와 길 안 복습**
- 레슨마다 그 레슨 단어들의 평균 p를 막대로 표시. 약해진 레슨(평균 p < 0.6)은 홈에서 "다시 단단하게" 복습을 권함.
- 시험: 시간이 지나면 막대가 줄고, 복습하면 다시 참.

## 7. 일부러 옮기지 않는 것
- **하트(틀리면 학습이 막힘)**: 초보자의 학습을 막고 유료 전환을 노리는 장치. 듀오링고 자신도 2025년 이후 바꾸는 중으로 알려짐 **[요약]**.
- **죄책감을 주는 알림 문구, 손실 회피를 키우는 연속 학습 걸기(내기)**: 효과는 있으나(7일 재방문 +14%) 학습자에게 불안을 줌. 우리 방패는 이미 "실패로 느끼지 않게" 하는 쪽.
- **A/B 실험·모집단 학습 가중치·실제 사람 리그**: 서버와 많은 사용자가 필요.

## 8. 확인하지 못한 주장
Birdbrain이 Elo의 일반화라는 설명(요약끼리 엇갈림), Birdbrain 2판의 LSTM 구조, HLR이 Birdbrain에 흡수됐다는 설명, 70% 목표(인터뷰 일화), 알림 보상의 정의,
리그 효과 수치(+17% 학습 시간 등), 방패 효과 수치, 연속 학습 7일이면 완주 3.6배 — 모두 1차 자료로 확인하지 못했어요.
연구 사이트(research.duolingo.com, blog.duolingo.com)와 데이터셋 서버(dataverse.harvard.edu)는 이 환경에서 막혀 있어 원문을 읽지 못했어요.
