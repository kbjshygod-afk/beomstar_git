# 10년 백테스트에서 찾은 규칙성 (2026-09-26)

## 목적

모의투자를 시작하기 전에, 10년 백테스트(2016-09 ~ 2026-09)에서 시장마다 반복해서 나타난 패턴이 있는지 확인한다. **룰을 바꾸기 위한 문서가 아니다.** 룰을 어떻게 기대하고 운용할지, 다음 검증 기간에 무엇을 시험할지 정하기 위한 기록이다.

## 자료와 방법

| 항목 | 내용 |
|---|---|
| 포트폴리오 거래 | `swing-results` 브랜치 `runs/20260925-205632-992e2fd` (현금 한도 안에서 RS 순 배분, 5개 시장 2,955건) |
| 신호 전체 | `runs/20260926-011225-a6c7886`의 `signals.csv`. 모든 신호를 현금 제약 없이 종목별로 따로 매매한 결과 (6,702건, 수수료 차감). 포트폴리오는 현금이 있는 신호만 사므로 거래 기록만 보면 편향이 생김 |
| 검정 | 신호일 지표 19개 × 5개 시장 = 90건. 지표 상위 1/3과 하위 1/3의 평균 순손익과 +20% 초과 비율을 비교. 무작위 섞기 2,000회로 p값 계산 |
| "규칙적" 기준 | p < 0.005 이고, 전반(2016-09 ~ 2021-09)과 후반(2021-09 ~ 2026-09)에서 방향이 같고, 여러 시장에서 반복 |
| 재현 | `python -m swing_engine.signal_study ...`(백테스트 워크플로가 실행), `python tools/signal_patterns.py RESULTS_DIR OUT.csv` |

90건 중 30건이 p < 0.05 였다(우연이라면 약 4.5건). 엄격 기준을 통과한 것은 12건이다.

## 핵심 요약

1. **수익은 극소수 거래에서 나온다.** 모든 시장에서 상위 10개 거래가 10년 순이익의 86~113%를 냈다. 큰 승자 하나를 놓치면 결과가 무너진다.
2. **손실은 빨리 끝나고 큰 승자는 오래 간다.** 큰 승자는 보유 3~4개월, 손실은 1~4주 안에 끝난다. 오래 버틴 거래일수록 큰 승자로 끝날 확률이 급격히 올라간다.
3. **하락장에 강하고 급등장에 약하다.** 코스닥을 뺀 4개 시장에서 지수가 오를수록 초과수익이 줄어든다. 지수가 떨어진 구간에서는 75~100% 확률로 지수를 이겼다.
4. **종목 강도가 셀수록 결과가 좋다.** RS 최상위, 52주 저점 대비 상승폭, 50일선 이격이 큰 신호일수록 큰 승자가 많다. 미국 2개 시장과 코스피에서 뚜렷하다. 이 지표들은 서로 상관이 있어 사실상 하나의 효과다. 포트폴리오는 현금을 RS 순으로 배분하므로 이미 이 효과를 일부 누리고 있다.
5. **규칙이 아닌 것:** 월별 계절성, 거래량 배수의 크기(1.4배를 넘은 뒤), 진입 갭, 지수 과열 여부는 시장 공통의 규칙이 아니었다.

## 1. 모든 시장 공통: 수익 구조

| 시장 | 상위 10거래의 순익 비중 | 손실 거래 보유 (중간값) | +20% 초과 승자 보유 (중간값) | 60봉 이상 버틴 거래 중 +20% 초과 | 최장 연속 손실 | 최고점 회복까지 최장 |
|---|---|---|---|---|---|---|
| S&P500 | 100% | 19봉 | 92봉 | 40% | 30회 | 573거래일 |
| 나스닥100 | 99% | 12봉 | 87봉 | 52% | 24회 | 941거래일 |
| 코스피 | 113% | 6봉 | 65봉 | 81% | 22회 | 498거래일 |
| 코스닥 | 86% | 7봉 | 64봉 | 87% | 21회 | 466거래일 |
| 크립토 | 112% | 3봉 | 78봉 | 90% | 16회 | 1,615일 |

- 표의 출처가 두 가지입니다.
  - 보유 기간 두 칸은 신호 전체 자료입니다.
  - 나머지 칸은 포트폴리오 거래 자료입니다.
- 순익 비중이 100%를 넘으면, 나머지 거래를 모두 합한 결과가 손실이라는 뜻입니다.
- "60봉 이상 버틴 거래"는 사후에 분류한 것입니다. 진입할 때 미리 알 수는 없습니다. 대신 **오래 버티는 거래를 일찍 팔면 안 된다**는 근거가 됩니다.

**큰 승자는 처음부터 잘 간다.**
- 큰 승자가 진입 후 가장 깊게 밀린 폭의 중간값은 −2~−4%입니다.
- 미국 두 시장에서는 큰 승자의 85%가 −5%까지 밀리지 않았습니다.
- 코스닥과 크립토는 흔들림이 큽니다. 큰 승자의 36~40%가 −5% 이상 밀렸다가 올라갔습니다.

**수익을 돌려주는 거래가 흔하다.**
- 손실로 끝난 거래 중 한때 +10% 이상이었던 비율:

  | 시장 | 비율 |
  |---|---|
  | 미국 두 시장 | 8~12% |
  | 코스피 | 23% |
  | 코스닥 | 32% |
  | 크립토 | 38% |

- 목표가 없이 50일선에서 청산하는 룰이 치르는 비용입니다. 대신 큰 승자를 끝까지 들고 가는 대가로 보면 됩니다.

## 2. 시장 국면: 하락장 방어, 급등장 열세

10년을 6개월씩 겹치지 않게 나눠 비교했습니다(시장별 19~20개 구간).

| 시장 | 지수 수익률과 초과수익의 순위상관 | 지수 하락 구간에서 지수를 이긴 비율 | 지수 급등 구간(상위 1/3)에서 이긴 비율 |
|---|---|---|---|
| S&P500 | −0.52 | 80% (5개 구간) | 33% |
| 나스닥100 | −0.50 | 75% (4) | 33% |
| 코스피 | −0.68 | 88% (8) | 17% |
| 코스닥 | +0.37 | 100% (8) | 83% |
| 크립토 | −0.96 | 89% (9) | 0% |

연도별로 보면 규칙성이 분명합니다.
- S&P500은 2018년(+14.1%p)과 2022년(+13.4%p) 하락장에서 지수를 이겼습니다. 2019년(−25.4%p)과 2021년(−22.0%p) 급등장에서는 크게 졌습니다.
- 코스피는 2025~2026년 급등장에서 −45%p, −50%p를 기록했습니다. 스캐너 계기판의 최근 1년 코스피 −74%p와 같은 현상입니다.
- 코스닥만 예외입니다. 레짐 필터가 없고 지수 자체가 10년간 약했기 때문에, 강한 종목이 거의 모든 해에 지수를 이겼습니다.

→ **지수가 급등하는 해에는 지수보다 뒤처지는 게 정상입니다.** 모의투자와 실전에서 이런 구간을 룰의 실패로 오해하면 안 됩니다.

## 3. 종목 선별: 강할수록 좋다

RS 백분위 구간별 결과입니다(신호 전체, 평균 순손익 / +20% 초과 비율 / 신호 수 / [전반 | 후반 평균]).

| 시장 | RS 70~80 | 80~90 | 90~95 | 95~100 |
|---|---|---|---|---|
| S&P500 | +0.7% / 5% / 1,134 [+0.9 \| +0.4] | +0.9% / 6% / 1,177 | +0.7% / 7% / 572 | **+5.8% / 15% / 577 [+2.7 \| +9.2]** |
| 나스닥100 | **−0.5% / 5% / 283 [−0.4 \| −0.5]** | +2.1% / 8% / 252 | +11.5% / 14% / 116 | +11.0% / 26% / 117 [+7.5 \| +15.8] |
| 코스피 | +1.8% / 11% / 389 | +2.9% / 10% / 392 | +6.3% / 14% / 195 | +5.6% / 16% / 214 [+1.8 \| +9.9] |
| 코스닥 | +7.8% / 18% / 424 | +6.4% / 13% / 338 | +11.4% / 20% / 188 | +7.1% / 19% / 198 |
| 크립토 | 표본 33~44건으로 판단 불가 | | | |

시장별로 정리하면:
- **S&P500:** 우위가 거의 전부 RS 95 이상에서 나옵니다.
- **나스닥100:** RS 70~80 신호는 전반과 후반 모두 손실이었습니다.
- **코스피:** RS 90 이상이 더 좋았습니다.
- **코스닥:** 뚜렷한 차이가 없습니다.

엄격 기준(p < 0.005, 전·후반 같은 방향)을 통과한 지표입니다. 모두 "상위 1/3이 하위 1/3보다 좋음" 방향입니다.

| 지표 | 통과한 시장 | 예: 하위 1/3 → 상위 1/3 평균 순손익 (+20% 초과 비율) |
|---|---|---|
| 52주 저점 대비 상승폭 | S&P500, 나스닥100, 코스피, 코스닥 | 코스피 +0.8% → +6.5% (7.8% → 15.6%) |
| RS 백분위 | S&P500, 나스닥100 | 나스닥100 −0.6% → +11.6% (5.4% → 19.0%) |
| 50일선 이격 | S&P500, 나스닥100 | S&P500 +0.5% → +3.5%, 11년 중 10년 같은 방향 |
| 직전 20일 수익 | S&P500, 나스닥100 | S&P500 +0.9% → +3.4% |
| 변동성(ATR%) | S&P500, 나스닥100 | 큰 승자 비율은 오르고 승률은 내려감 (손절도 많고 큰 승자도 많음) |

- 이 지표들은 서로 상관이 있습니다(S&P500 순위상관 0.2~0.65). 따로 떨어진 발견 5개가 아니라, 대체로 **"이미 강하게 오르고 있는 종목이 더 간다"**는 효과 하나입니다.
- 포트폴리오는 현금을 RS 순으로 배분합니다. 그래서 체결된 거래의 RS 90 이상 비중이 이미 높습니다.

  | 시장 | 전체 신호 | 체결 거래 |
  |---|---|---|
  | S&P500 | 33% | 64% |
  | 나스닥100 | 30% | 39% |
  | 코스피 | 34% | 51% |

## 4. 규칙이 아니었던 것

| 확인한 것 | 결과 |
|---|---|
| 월별 계절성 | 주식 4개 시장 × 12개월 = 48개 중 전·후반 모두 같은 방향으로 평균보다 3%p 넘게 벗어난 달은 3개(나스닥100 3월, 코스피 8월, 코스닥 11월). 우연으로 나올 수 있는 수준 |
| 거래량 배수 크기 | 1.4배 기준을 넘긴 뒤에는 더 커도 성과 차이 없음 (5개 시장 모두 유의하지 않음) |
| 진입 갭 | 유의하지 않음 |
| 지수 과열 | 나스닥100에서만 지수가 200일선보다 12.9% 넘게 위일 때 신호 성과가 나빴음(평균 −0.3%, 9.2% 이하일 때는 +6.0%, 6년 중 6년 같은 방향). S&P500은 무관, 코스닥은 반대라 공통 규칙 아님 |
| 같은 날 신호 수 | 코스피에서만 3건 이상 동시에 나온 날의 성과가 좋았음(+6.8% vs +2.0%). 다른 시장은 유의하지 않음 |
| 크립토 | 신호 136건으로 표본이 작아 어떤 지표도 판단 불가 |

## 5. 해석의 한계 (리스크)

- **생존편향:** 과거 백테스트를 **현재** 지수 구성종목으로 돌렸습니다.
  - 강하게 오르다 무너져 지수에서 빠진 종목은 자료에 없습니다. 그래서 "강할수록 좋다"는 효과가 부풀려졌을 수 있습니다.
  - 오늘의 시가총액 상위로 유니버스를 만든 코스피·코스닥에서 특히 그렇습니다.
- **같은 날 신호의 쏠림:** 같은 날 신호들은 결과가 함께 움직입니다. 그래서 p값이 실제보다 낙관적입니다. 이를 보완하려고 전·후반과 연도별 방향을 함께 봤습니다.
- **같은 자료에서 찾은 패턴:** 발견한 자료로 다시 검증하면 좋아 보일 수밖에 없습니다. 새 기간에서 다시 확인해야 합니다.
- **추정값 7개:** RS 계산 방식 등이 스캐너 원본과 다르면 RS 구간별 수치도 달라집니다.

## 7. 의사결정 포인트

- **RS 기준을 올릴지(예: 70 → 90):** 지금은 권하지 않는다.
  - 발견한 자료로 룰을 고치면 과최적화가 되고, 생존편향이 섞였을 수 있다.
  - 포트폴리오는 이미 RS 순으로 배분하고 있다.
  - 스캐너 룰과 달라지면 모의투자가 스캐너를 검증하지 못한다.
- 가설 ①·②를 모의투자 계획서의 "관찰 항목(판정에는 쓰지 않음)"으로 미리 등록할지는 대표님이 결정한다.
