# 🔊 자연스러운 원어민 음성 녹음하기 (Google Cloud Text-to-Speech 설정 안내)

지금 랭귀지 스타터는 휴대폰·컴퓨터에 들어 있는 음성으로 외국어를 읽어 줍니다. 그래서 기기마다 목소리 품질이 다르고, 어떤 기기는 기계음처럼 들립니다.
앱이 읽어 주는 모든 외국어 문장(약 7,400개)을 **Google의 자연스러운 음성으로 한 번만 녹음**해서 앱에 넣으면, 어떤 기기에서든 같은 목소리로 들을 수 있습니다.

녹음은 Claude가 합니다. 여기서는 **Google Cloud 쪽 준비**만 하면 됩니다. 30분 정도 걸립니다.

> 💰 **요금**: Google은 이 음성(Chirp 3 HD)을 **매달 100만 글자까지 무료**로 줍니다.
> 이 앱 5개 언어를 전부 녹음해도 약 **12만 3천 글자**라서, 한 번 전체 녹음은 **약 0원**입니다.
> 혹시 무료 한도를 넘어도 100만 글자당 30달러라서, 12만 글자를 전부 돈을 내고 해도 약 4달러입니다.
> (2026년 9월에 확인한 가격입니다. 가격은 바뀔 수 있으니 시작 전에 [가격 페이지](https://cloud.google.com/text-to-speech/pricing)를 꼭 확인하세요.
> 같은 달에 같은 결제 계정으로 다른 곳에서 쓴 양과 합쳐서 셉니다.)
>
> 참고로 다른 등급의 무료 한도: Neural2 매달 100만 글자(이후 100만 글자당 16달러), WaveNet·Standard 합쳐서 매달 400만 글자(이후 100만 글자당 4달러).

---

## 1. Google Cloud 프로젝트 만들기 (3분)
1. https://console.cloud.google.com 에 구글 계정으로 들어갑니다. 처음이면 약관에 동의합니다.
2. 화면 위쪽의 **프로젝트 선택** → **새 프로젝트**를 누릅니다.
3. 프로젝트 이름에 `lang-starter-voice`(아무거나 괜찮음)를 넣고 **만들기**를 누릅니다.
4. 만들어지면 화면 위쪽 프로젝트 이름이 방금 만든 프로젝트인지 확인합니다. 이후 모든 단계는 이 프로젝트에서 합니다.

> 로그인 기능 때 만든 Firebase 프로젝트와는 **따로** 만드는 것을 권합니다.
> Firebase 프로젝트에 결제 계정을 연결하면 Firebase 요금제가 바뀌기 때문입니다.

## 2. 결제 계정 연결 (카드 등록, 5분)
무료 한도 안에서만 써도 Google은 **카드 등록(결제 계정)** 을 요구합니다.
1. 왼쪽 메뉴(☰) → **결제**를 누릅니다.
2. "이 프로젝트에는 결제 계정이 없습니다"가 나오면 **결제 계정 연결**을 누릅니다.
   - 결제 계정이 하나도 없으면 **결제 계정 만들기** → 국가 **대한민국** → 이름·주소·카드 정보를 넣습니다.
   - 처음 가입하는 계정이면 무료 체험 크레딧을 함께 주기도 합니다. 있으면 좋고, 없어도 괜찮습니다.
3. 결제 화면에 방금 만든 프로젝트가 연결되어 있으면 끝입니다.

## 3. 예산 알림 걸기 (2분, 꼭 하세요)
혹시 모를 과금을 바로 알 수 있게 알림을 겁니다.
1. 왼쪽 메뉴(☰) → **결제** → **예산 및 알림** → **예산 만들기**를 누릅니다.
2. 이름: `음성 녹음`, 범위(프로젝트): `lang-starter-voice`를 고릅니다.
3. 금액: **지정된 금액** → `1,000원`(또는 1달러)을 넣습니다.
4. 알림 기준: 50% · 90% · 100%(기본값 그대로)로 두고, **결제 관리자와 사용자에게 이메일 알림**이 켜져 있는지 확인한 뒤 **완료**를 누릅니다.

> ⚠️ 예산 알림은 **알려 주기만** 하고 사용을 자동으로 멈추지는 않습니다. 알림 메일이 오면 7번(정리하기)을 바로 하면 됩니다.

## 4. Cloud Text-to-Speech API 켜기 (1분)
1. https://console.cloud.google.com/apis/library/texttospeech.googleapis.com 을 엽니다.
   (또는 왼쪽 메뉴 → **API 및 서비스** → **라이브러리**에서 `Cloud Text-to-Speech API` 검색)
2. 위쪽 프로젝트가 `lang-starter-voice`인지 확인하고 **사용**을 누릅니다.

## 5. API 키 만들기 — 이 API만 쓰도록 제한 (3분)
1. 왼쪽 메뉴 → **API 및 서비스** → **사용자 인증 정보**를 엽니다.
2. 위쪽 **+ 사용자 인증 정보 만들기** → **API 키**를 누릅니다.
3. 키가 만들어지면 **키 수정**(또는 키 이름을 눌러 편집 화면)으로 들어갑니다.
   - 이름: `tts-녹음-임시`
   - **애플리케이션 제한사항**: `없음` (녹음을 하는 클라우드 컴퓨터의 주소가 매번 달라서 IP로 막을 수 없습니다)
   - **API 제한사항**: **키 제한**을 고르고 목록에서 **Cloud Text-to-Speech API** 하나만 체크합니다.
   - **저장**을 누릅니다.
4. 키 값(`AIza…`로 시작)을 **복사**해 둡니다. 다음 단계에서 딱 한 번 붙여 넣습니다.

> 🔒 **키는 비밀번호처럼 다룹니다.** Claude와의 채팅, 이슈, 카톡, 커밋 어디에도 붙여 넣지 마세요.
> Claude도 채팅으로 키를 달라고 하지 않습니다. 키는 6번의 환경 설정에만 넣습니다.

## 6. Claude Code 클라우드 환경에 키 넣기 (2분)
1. claude.ai/code 에서 이 저장소의 세션 화면을 엽니다.
2. 화면 위쪽 **제목 표시줄의 클라우드 환경 메뉴**(환경 이름) → **Edit(편집)** 을 누릅니다.
3. **API credentials** 칸이 있으면 그곳에, 없으면 **환경 변수** 칸에 아래처럼 한 줄을 넣습니다.
   ```
   GOOGLE_TTS_API_KEY=여기에_복사한_키
   ```
   변수 이름은 정확히 `GOOGLE_TTS_API_KEY`여야 합니다. 저장합니다.
4. 이미 열려 있는 세션에는 새 키가 들어가지 않습니다. **새 세션을 시작**하고 이렇게 말하면 됩니다.
   > **음성 녹음 진행해줘**

Claude가 하는 일: ① 네트워크 없이 개수·예상 요금 계산(`--dry-run`) → ② 언어마다 목소리 이름 확인(`--list-voices`) → ③ 언어마다 몇 개만 시험 녹음 → ④ 전체 녹음(약 15~40분, 요청 한도에 걸리면 1시간 넘게도 걸림, 끊기면 이어서) → ⑤ 끝이 잘린 녹음을 찾아 다시 녹음(`check.py`) → ⑥ 결과를 알려 드립니다.
명령과 옵션은 [`tools/tts/README.md`](../tools/tts/README.md)에 있습니다.

## 7. 녹음이 끝나면 정리하기 (3분, 꼭 하세요)
1. **키 삭제**: **API 및 서비스** → **사용자 인증 정보** → `tts-녹음-임시` 오른쪽 ⋮ → **API 키 삭제**.
2. **환경 변수 삭제**: 6번의 Edit 화면에서 `GOOGLE_TTS_API_KEY` 줄을 지우고 저장합니다.
3. (선택) **API 사용 중지**: 4번 화면에서 **사용 중지**를 누릅니다.
4. 하루쯤 뒤 **결제** → **보고서**에서 요금이 0원(또는 예상한 금액)인지 확인합니다.

나중에 학습 데이터(문장)를 고치면 바뀐 문장만 새로 녹음하면 됩니다(보통 몇백 글자 → 0원). 그때 5~6번을 다시 하고 새 세션에서 "음성 녹음 진행해줘"라고 하면 됩니다.

## 자주 묻는 질문

**Q. 키가 새어 나간 것 같아요.**
바로 7-1번처럼 키를 삭제하세요. 5번에서 이 API만 쓰도록 제한해 두었기 때문에 다른 Google 서비스에는 쓸 수 없고, 3번 예산 알림이 과금을 알려 줍니다.

**Q. 예산 알림 메일이 왔어요.**
7번을 해서 키를 지우면 더 이상 과금되지 않습니다. 결제 → 보고서에서 어디에 쓰였는지 볼 수 있습니다.

**Q. 녹음된 목소리가 마음에 안 들어요.**
Claude에게 "목소리 바꿔서 다시 녹음해줘"라고 하면 됩니다. 5~6번의 키가 필요합니다.

**Q. 중국어 발음이 가끔 이상해요.**
한 글자가 여러 소리를 가진 한자(예: 还·行·得·了)를 문맥과 다르게 읽는 경우가 있을 수 있습니다. 이번 녹음 작업에서는 따로 고치지 않았습니다. 이상한 문장을 알려 주시면 따로 처리합니다.
