# Minervini Swing Watch (TradingView Pine Script v5)

맥에서 돌리는 **"매매 스캐너"(미너비니 스캐너)의 라이브 룰**을 TradingView 차트에서 그대로 보고, 알림을 받고,
한 종목 단위로 백테스트하기 위한 스크립트입니다. 룰은 구글드라이브 `매매스캐너` 폴더의
타점표(2026-09-04판)에 적힌 내용을 기준으로 옮겼습니다.

- **지표(관찰·알림)**: [`minervini_swing_watch.pine`](./minervini_swing_watch.pine)
- **전략(백테스트)**: [`minervini_swing_watch_strategy.pine`](./minervini_swing_watch_strategy.pine) — 같은 신호 로직
- 일봉 기준. 모든 판정은 확정봉(`barstate.isconfirmed`)에서만 하므로 repaint가 없습니다.
- 기계적 룰 출력이며 투자 자문이 아닙니다.

## 설치

1. TradingView 차트 → 하단 `Pine Editor`
2. 파일 내용을 붙여넣고 `Add to chart`
3. ⚙️ → Inputs → **시장** 프리셋을 종목이 속한 시장으로 선택 (가장 중요)

## 1. 룰

### 진입 (신호 확정 → 다음 거래일 시가)
모두 충족해야 합니다.

| 조건 | 내용 |
|---|---|
| 트리거 돌파 | 종가가 트리거(피벗 = 직전 N봉 최고가, 기본 20봉)보다 높게 마감 |
| 거래량 | 당일 거래량 ≥ 직전 50일 평균 × 1.4 |
| 돌파폭 상한 | 종가가 트리거보다 15% 넘게 위면 추격 구간으로 제외 (크립토는 상한 없음) |
| 후보 조건 | 미너비니 트렌드 템플릿 8/8 |
| 시장 레짐 | 시장별 레짐 ON (아래 표) |

**갭은 따지지 않습니다.** 스캐너의 "+5% 갭이면 건너뛰기" 규칙은 검증에 실패해 삭제됐습니다.

### 트렌드 템플릿 8개
1. 종가 > 150일선, 종가 > 200일선
2. 150일선 > 200일선
3. 200일선이 약 1개월(22봉) 전보다 높음
4. 50일선 > 150일선, 50일선 > 200일선
5. 종가 > 50일선
6. 종가가 52주 최저가보다 30% 이상 위
7. 종가가 52주 최고가의 25% 이내
8. RS — 스캐너는 유니버스 내 백분위 70 이상. 차트 한 개로는 백분위를 낼 수 없어 **지수 대비 가중 1년 수익률 우위**로 근사합니다

### 청산 3규칙
1. **손절가 도달 시 즉시** — 진입가(다음 시가) 기준. 매수와 동시에 손절 주문을 거는 것이 전제입니다.
2. **종가가 50일선 아래로 마감하면 다음 거래일 시가에 전량 청산**
3. **목표가는 두지 않습니다** — 스캐너 백테스트에서 이익의 77~84%가 +20%를 넘는 소수 승자(거래의 8~9%)에서 나왔고, 분할 익절(2R/3R)은 그 꼬리를 잘라 기각됐습니다.

### 시장별 설정 (프리셋)

| 시장 | 손절 | 레짐 (신규 진입 허용 조건) | 벤치마크 |
|---|---|---|---|
| S&P500 | -10% | 지수 > 200일선 | `SP:SPX` |
| 나스닥100 | -7% | 지수 > 200일선 | `NASDAQ:NDX` |
| 코스피 | -7% | 지수 > 200일선 **그리고** > 20일선 | `KRX:KOSPI` |
| 코스닥 | -10% | 무필터 (레짐을 얹으면 오히려 악화돼 의도적으로 제외) | `KRX:KOSDAQ` |
| 크립토 | -10% | BTC > 200일선 | `BINANCE:BTCUSDT` |

`직접 설정`을 고르면 벤치마크·레짐·손절·돌파폭 상한·1년 봉 수를 직접 넣을 수 있습니다.

### 수량 (스캐너 배분 규칙)
신호당 **자본 × 0.75% 리스크 ÷ 손절폭**. 손절 7%면 비중 약 10.7%, 10%면 7.5%입니다.
지표는 상태 테이블에 권장 수량을, 전략은 `strategy.equity` 기준으로 같은 방식의 수량을 씁니다.

## 2. 이전 버전에서 바뀐 점

스캐너 룰과 충돌하거나 스캐너에 없는 규칙은 뺐습니다.

| 이전 버전 | 지금 | 이유 |
|---|---|---|
| +10% / +20% 분할 익절 | **삭제**, 목표가 없음 | 스캐너 실험에서 기각 — 수익의 원천인 꼬리를 자름 |
| 손절 -5% / -8% | 시장별 -7% / -10% | 스캐너 채택값 (S&P500·코스닥은 -10%가 여러 구간에서 우세) |
| 20일선 이탈·REDUCE·HOLD | 50일선 종가 이탈 → 다음 시가 전량 | 스캐너 청산 규칙 |
| 20/60/120일선 정배열 + 100점 점수 | 트렌드 템플릿 8/8 | 스캐너 후보 조건. 점수로 신호를 거르지 않음 |
| SETUP → 재돌파 확인 2단계 | 신호 확정 → 다음 시가 | 추격 방지는 돌파폭 15% 상한이 맡음 |
| 거래량 1.5배(20일 평균) | 1.4배(50일 평균) | 스캐너 룰 |
| 과열 제외 7종 | 삭제 | 스캐너에 없음 (갭 스킵도 검증 실패로 삭제된 규칙) |
| 시장 필터: 벤치마크 > 20일선 | 시장별 레짐 (위 표) | 스캐너 룰 |
| 거래대금 30억 필터 (기본 켜짐) | 보조 필터로 남기되 **기본 꺼짐** | 스캐너에 없음. 켜면 스캐너와 신호가 달라짐 |

## 3. 확인이 필요한 가정

스캐너 원본 코드는 맥에만 있어 아래 값은 타점표 숫자와 일반적인 미너비니 정의로 추정했습니다.
모두 입력값으로 빼 두었으니, 맥에서 원본 코드를 확인하면 그 값으로 맞추세요.

| 항목 | 이 스크립트의 기본값 | 근거 |
|---|---|---|
| 트리거(피벗) 기간 | 직전 20봉 최고가 (당일 제외) | 타점표상 트리거가 52주 고점과 다른 경우가 많아 짧은 베이스의 고가로 추정 |
| 거래량 평균 | 직전 50일 (당일 제외) | 미너비니의 "50일 평균 대비 +40%" 기준 |
| RS | 종목 − 벤치마크의 가중 1년 수익률 ≥ 0%p | 스캐너는 유니버스 백분위(≥70). 단일 차트에서는 계산 불가 |
| 52주 고가·저가 | 종가 기준 | 타점표의 "52주 고점 대비" 값이 종가 기준으로 맞아떨어짐 |
| 200일선 상승 | 22봉 전보다 높음 | 트렌드 템플릿 "최소 1개월 상승" |
| 수축비 10/40 | 10일 평균 TR ÷ 40일 평균 TR | 표시용. 1보다 큰 값이 있어 기간 고저폭 비율은 아님 |
| 전략 비용 | 편도 수수료 0.2% | 스캐너의 슬리피지 가정(20bp)에 근접. Properties에서 조정 |

## 4. 스캐너 백테스트 참고 수치

스캐너 계기판(2026-09-04 생성)에 적힌 **라이브 룰 기준 연율 수익(CAGR) − 지수 CAGR**입니다.
여러 종목을 동시에 들고 가는 포트폴리오 결과라, 이 전략을 한 종목에 돌린 결과와는 다릅니다.

| 시장 | 10년 | OOS | 최근 1년 |
|---|---|---|---|
| S&P500 | +1.1%p | +12.4%p | +42.8%p |
| 나스닥100 | +2.0%p | +23.5%p | +67.5%p |
| 코스피 | **-2.1%p** | **-6.9%p** | **-74.1%p** |
| 코스닥 | +21.1%p (MDD -53.7%) | +49.6%p | +95.9%p |
| 크립토 | **-23.8%p** | **-42.0%p** | +30.2%p |

- **코스피는 세 구간 모두 지수에 못 미쳤습니다.** 스캐너 타점표도 코스피 밴드에 "지수 미달" 경고를 붙입니다.
- 크립토는 "조건부 유효"입니다. 위험조정 수익·낙폭은 BTC 보유보다 낫지만 절대수익은 못 미칩니다.
- 승률은 30%대입니다. 지는 거래를 손절폭에서 무조건 자르는 규율이 수익의 전제입니다.
- 유니버스가 현재 지수 구성종목이라 생존편향이 있습니다. 모든 수치는 낙관적 상한으로 보세요.
- 실전 검증(2026-07-17 시작)은 판정 기준이 사전에 고정돼 있고, 90일이 차기 전에는 결론을 내지 않습니다.

## 5. 지표 화면 읽는 법

### 라벨
| 라벨 | 의미 |
|---|---|
| `BUY 신호 / 다음 시가 진입` | 모든 진입 조건 충족. 다음 거래일 시가 매수 + 동시에 손절 주문 |
| ▲ (아래 작은 삼각형) | 시가 진입 봉. 이 봉부터 손절선(빨간 선)이 그려짐 |
| `STOP -x%` | 손절가 도달 — 전량 청산 |
| `50일선 이탈 / 다음 시가 청산` | 종가가 50일선 아래로 마감 — 다음 거래일 시가 전량 청산 |
| `청산 ±x%` | 50일선 청산이 실행된 봉과 손익 |
| `레짐 OFF` / `추격 제외 +x%` / `거래량 부족 x배` | 트렌드 템플릿은 통과했고 돌파도 했지만 진입하지 않는 이유 |

### 상태 테이블 (확정봉 기준)
시장·레짐, 트렌드 템플릿 x/8, RS 프록시, 52주 고점 대비, 수축비·거래량비, 트리거와 피벗까지 거리,
당일 거래량 배수, 상태, 진입가·손절가, 50일선 여유, 권장 수량을 보여줍니다.
상태는 타점표의 우선순위와 같은 말을 씁니다: `신호 확정` · `1순위 · 임박(피벗 1% 이내)` ·
`2순위 · 근접(3% 이내)` · `3순위 · 관찰` · `추격 제외` · `레짐 OFF` · `후보 아님`.

### 알림
`신호 확정`, `손절`, `청산선 이탈`, `피벗 임박` 네 가지를 `alertcondition`으로 제공합니다.
TradingView 알림 생성 시 조건에서 이 지표와 항목을 고르고, 빈도는 "봉 마감 시 1회"를 권장합니다.

## 6. 전략(백테스트) 사용법

1. `minervini_swing_watch_strategy.pine`을 차트에 추가하고 시장 프리셋을 맞춥니다.
2. Strategy Tester에서 결과를 봅니다. 신호 확정 다음 봉 시가에 진입하고, 손절은 진입과 함께 걸리며,
   50일선 종가 이탈 시 다음 봉 시가에 청산합니다.
3. 초기 자본은 1억(종목 통화)입니다. 수량이 리스크 비율로 정해지므로 수익률(%)로 보세요.
   미국 주식·크립토는 `소수점 수량`을 켜야 고가주에서 0주가 나오지 않습니다.
4. 이 전략은 **한 종목만** 봅니다. 스캐너처럼 여러 신호를 동시에 들고 가며 RS 순으로 현금을 배분하는
   구조가 아니므로, 위 4절의 시장별 수치와 비교하지 마세요. 승률이 낮고 손실 거래가 많아 보이는 것은
   이 룰의 정상적인 모습입니다(승률 30%대, 수익은 소수의 큰 승자에서 나옴).

## 참고

- 이 스크립트는 매수 후보를 보여주는 도구이며 투자 자문이 아닙니다. 판단과 책임은 사용자에게 있습니다.
- 스캐너 룰이 바뀌면(맥의 `reports/` 실험 결과로 채택·기각) 이 스크립트도 같이 맞춰야 합니다.
