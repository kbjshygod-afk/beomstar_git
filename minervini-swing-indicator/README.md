# Minervini Swing Watch (TradingView Pine Script v5)

Mark Minervini식 스윙 매매 원칙을 기반으로 한 **매수 후보 필터링 도구**입니다.
자동매매 전략이 아니며, 투자 추천도 아닙니다. 상승추세 + 변동성 축소(VCP) + 거래량 동반 돌파 조건을
확정봉(bar close) 기준으로만 판단하여 참고 신호를 표시합니다.

- **지표(관찰/알림)**: [`minervini_swing_watch.pine`](./minervini_swing_watch.pine) — 차트 표시 + 알림용
- **전략(백테스트)**: [`minervini_swing_watch_strategy.pine`](./minervini_swing_watch_strategy.pine) — 동일한 신호 로직으로 과거 성과 검증용
- Pine Script v5, TradingView에 그대로 붙여넣어 사용 가능
- 기본 보유 기간 가정: 5~20거래일 스윙
- 모든 신호는 `barstate.isconfirmed`(확정봉) 기준으로만 계산/표시되어 repaint가 발생하지 않습니다.

## 설치 방법

1. TradingView 차트 열기 → 하단 `Pine Editor` 탭
2. 용도에 맞는 파일 선택
   - 실시간 관찰 + 알림 설정 → `minervini_swing_watch.pine`
   - 과거 데이터 성과(승률/손익비/MDD 등) 검증 → `minervini_swing_watch_strategy.pine`
3. 내용 전체 복사 → 붙여넣기 → `Add to chart`
4. 지표/전략 이름(⚙️ 톱니바퀴 아이콘) 클릭 → Inputs 탭에서 설정값 조정

## 1. 신호 조건 설명

### 상승추세 조건 (Trend) — 점수 항목
- `종가 > 20일선`(8점), `20일선 > 60일선`(8점), `60일선 > 120일선`(8점)
- `종가 > 200일선`(6점) → 강한 추세
- `200일선 상승 중`(5점) → 가산점
- 추세 항목 합계 35점

### 시장 국면 필터 (Market Filter)
- 벤치마크 심볼(기본 `KRX:KOSPI`, 자유 변경 가능)의 종가가 20일선 위/아래인지로 시장 강약 판단
- 시장이 약하면(벤치마크 종가 < 20일선) **설정(SETUP) 자체가 차단**되고 `MARKET WEAK` 경고로 대체
- `시장 필터 사용` 옵션으로 on/off 가능. 점수 항목으로도 10점 반영(필터 꺼짐/통과 시 10점, 약세 시 0점)

### 돌파 조건 (Breakout)
- 확정봉 종가가 최근 N일(기본 20일, 당일 제외) 고가를 상향 돌파할 때 성립
- 이 고가 레벨은 "최근 N일 고가"이자 "박스권 상단"으로 함께 해석
- 장중 고가가 아닌 **확정봉 종가 기준**으로만 판단(`ta.crossover(close, priorHigh)`)

### 거래량 조건 (Volume) — 점수 항목
- 강한 거래량(20점): 당일 거래량 > 20일 평균 거래량 × 배수(기본 1.5)
- 보통 거래량(10점): 평균 이상 ~ 1.5배 미만
- 평균 거래량에도 못 미치는 "거래량 없는 돌파"(0점)는 과열 제외 조건으로 분류되어 SETUP 자체를 차단

### VCP / 변동성 축소 조건 (5개 중 설정한 개수 이상 충족 — 하드 게이트) — 점수 항목
1. 최근 ATR 평균이 이전 ATR 평균보다 감소
2. 최근 10일 고가-저가 변동폭이 이전 10일보다 축소
3. 조정 구간(최근 10일) 평균 거래량이 20일 평균보다 감소
4. 최근 20일 고점 대비 낙폭이 -10% 이내(과도한 조정 아님, 고정 기준)
5. 종가가 최근 N일(기본 60일) 고점 대비 허용 낙폭(기본 -15%) 이내

`VCP 세부조건 중 최소 충족 개수`(기본 3/5)를 넘지 못하면 SETUP 자체가 차단됩니다(하드 게이트).
점수 항목으로는 충족 개수 × 5점(최대 25점)이 반영됩니다.

### 거래대금 필터 (한국장 유동성) — 점수 항목
- 거래대금 = 종가 × 거래량
- 사용자가 입력한 `최소 거래대금`(기본 30억원)에 못 미치면 SETUP 자체가 차단되고 `LOW LIQUIDITY` 표시
- 점수 항목: 최소 거래대금의 3배 이상 10점, 1.5배 이상 7점, 1배 이상 4점, 미달 0점(=하드 게이트로 차단)

### 조건 점수화 (100점 만점)
| 항목 | 배점 |
|---|---|
| 추세 | 35 |
| 거래량 | 20 |
| VCP | 25 |
| 시장 국면 | 10 |
| 거래대금(유동성) | 10 |
| **합계** | **100** |

- **80점 이상** → STRONG BUY WATCH 등급
- **60~79점** → WEAK BUY WATCH 등급(관찰 후보, 실제 매수 신호 아님)
- **60점 미만** → 신호 없음

과열/시장약세/유동성부족/VCP미달 중 하나라도 해당하면 점수와 무관하게 SETUP 자체가 차단됩니다(하드 게이트).
즉 점수는 "돌파 + 하드 게이트를 모두 통과한" 경우에만 등급을 STRONG/WEAK로 나누는 데 사용됩니다.

### 과열 제외 조건 (Overheated / Avoid) — 하나라도 해당하면 SETUP 차단
- 당일 상승률 ≥ 12% (기본값)
- 최근 5거래일 상승률 ≥ 20% (기본값)
- 종가의 20일선 대비 이격도 > 15% (기본값)
- 평균 거래량에도 못 미치는 거래량 없는 돌파
- 종가 < 20일선
- 20일선 < 60일선
- 장대양봉 다음날 윗꼬리가 길고 종가가 약한 경우(추세 반전 경고)

> 노이즈 감소를 위해 `MARKET WEAK` / `OVERHEATED` / `AVOID` / `LOW LIQUIDITY` / `VCP WEAK` 라벨은
> **돌파는 발생했고 점수도 60점 이상이었지만** 특정 하드 게이트 하나 때문에 막힌 경우에만 표시됩니다.
> 여러 사유가 겹쳐도 한 번에 하나의 라벨만(우선순위: 과열 > 시장약세 > 유동성부족 > VCP부족) 표시해 차트가 지저분해지지 않도록 했습니다.

### SETUP과 진입 확인(ENTRY) — 신호봉 당일 추격 매수 금지
과거 버전과 달리, **돌파가 발생한 당일에는 절대 BUY 신호를 표시하지 않습니다.**

1. **SETUP(설정)**: 돌파 + 모든 하드 게이트 통과 + 점수 60점 이상인 날. 이 날의 고가를 `설정일 고가`로 저장하고
   등급(STRONG/WEAK)을 점수 기준으로 미리 확정합니다. 차트에는 작은 `SETUP(점수)` 라벨만 표시됩니다.
2. **ENTRY CONFIRM(진입 확인)**: 설정일 다음 확정봉부터, 종가가 `설정일 고가`를 재돌파하는 시점에만
   `STRONG BUY WATCH` / `WEAK BUY WATCH`가 표시됩니다. 이 재돌파는 두 가지 경우를 모두 포함합니다.
   - 다음 봉이 곧바로 설정일 고가를 돌파(추세 지속 확인)
   - 다음 봉 이후 눌림(조정)을 거친 뒤, 나중에 같은 레벨을 재돌파(돌파 후 눌림 → 재돌파 패턴)
3. 대기 중(진입 미확인) 상태에서 **20일선 이탈** 또는 **최대 대기 봉수(기본 10봉)** 초과 시 해당 SETUP은
   조용히 무효화되고, 이후 새로운 SETUP을 다시 기다립니다.
4. 진입 확인 시점에 다시 과열 조건에 해당하면(예: 대기 중 급등) 그 진입은 취소됩니다.
5. **이미 진입이 확인되어 활성 상태인 트레이드(지표 버전: 진입 기준가 보유 중 / 전략 버전: 포지션 보유 중)가
   있으면 새로운 SETUP을 등록하지 않습니다.** 한 번에 하나의 후보/포지션만 추적하며, 현재 트레이드가
   STOP 또는 TAKE PROFIT 2로 종료된 뒤에야 다음 SETUP을 새로 찾기 시작합니다. 이 기간 중 발생하는
   돌파는 거래량이 좋으면 참고용 `BREAKOUT` 태그로만 표시됩니다.

### 진입 기준가 / 손절 / 익절
- **ENTRY CONFIRM이 발생한 확정봉의 종가** = Entry Reference Price로 저장(설정일 종가가 아님)
- 손절선 1: 진입가 대비 기본 -5% (조정 가능) → 이탈 시 `STOP` 표시
- 손절선 2: 진입가 대비 기본 -8% (조정 가능, 보조 참고선)
- 구조적 손절: 설정일의 돌파 기준선 이탈도 `STOP` 트리거에 포함
- `RISK WARNING`: 손절선 1 근접 + 거래량 증가 장대음봉 발생 시
- 익절선 1/2: 진입가 대비 기본 +10% / +20% → 도달 시 `TAKE PROFIT 1` / `TAKE PROFIT 2`
- `HOLD`: 진입 이후 20일선 위 유지(기본 표시 꺼짐, 매일 뜰 수 있어 필요 시 켜서 사용)
- `REDUCE`: 진입 이후 장대음봉 + 거래량 증가 + 20일선 하향 이탈 시

### 포지션 리스크(참고용, 차트 우측 상단 테이블 — 지표 버전만 해당)
```
허용 손실금 = 계좌금액 × 1회 허용 손실률
1주당 손실금 = 진입 기준가 - 손절선1
적정 매수 수량 = 허용 손실금 / 1주당 손실금
```
테이블에는 현재 매수 후보 점수(0~100)도 매 봉 함께 표시됩니다.

### 알림(Alert)
지표 버전에는 아래 `alertcondition`이 정의되어 있어 TradingView `알림 만들기` 창에서 조건으로 선택할 수 있습니다.

| 알림 | 발생 시점 |
|---|---|
| SETUP 감지 | 돌파 + 하드 게이트 통과 + 점수 60점 이상 |
| STRONG BUY WATCH | 재돌파로 STRONG 진입 확인 |
| WEAK BUY WATCH | 재돌파로 WEAK 진입 확인 |
| STOP | 손절선/구조적 손절 이탈 |
| RISK WARNING | 손절선 근접 + 거래량 증가 장대음봉 |
| TAKE PROFIT 1 / 2 | +10% / +20% 도달 |
| REDUCE | 추세 이탈 + 거래량 증가 장대음봉 |

### 전략(백테스트) 버전 동작 방식
- 신호 로직(추세/돌파/거래량/VCP/과열/거래대금/점수/SETUP→ENTRY 상태 머신)은 지표 버전과 완전히 동일합니다.
- ENTRY CONFIRM 발생 시 `strategy.entry`로 다음 봉 시가에 진입하며, 수량은 `계좌 자산(strategy.equity) ×
  1회 허용 손실률 ÷ (진입 기준가 - 손절선1)` 로 리스크 비례 계산됩니다.
- 청산은 `strategy.exit`로 익절선1(포지션 50%)/익절선2(잔여 100%)와 손절선1을 동시에 브래킷 주문으로 걸고,
  추세(20일선)·구조적 손절 이탈 시 `strategy.close`로 즉시 종료, REDUCE 조건 시 잔여 물량의 50%를 축소합니다.
- `WEAK BUY WATCH 등급도 진입에 포함` 옵션(기본 켜짐)을 꺼서 STRONG 등급만 백테스트할 수 있습니다.
- 계좌금액/수수료/슬리피지는 `strategy()` 선언부에 하드코딩된 기본값(초기자본 1천만원, 수수료 0.25%,
  슬리피지 2틱)이며, TradingView `Properties` 탭에서 직접 조정할 수도 있습니다.

## 2. 설정값 변경 방법

지표/전략 이름 옆 ⚙️ 클릭 → `Inputs` 탭에서 그룹별로 조정:

| 그룹 | 주요 항목 |
|---|---|
| 이동평균 설정 | 20/60/120/200일 기간 |
| 돌파 조건 | 돌파 기준 기간, 고점 근접 기준 기간, 허용 낙폭 |
| 거래량 조건 | 평균 기간, 증가 배수 |
| VCP 조건 | ATR 기간, ATR 축소 비교 기간, 최소 충족 개수 |
| 과열 제외 조건 | 당일/5일 과열 상승률, 이격도 제한 |
| 시장 국면 필터 | 사용 여부, 벤치마크 심볼 |
| 거래대금 필터(한국장) | 사용 여부, 최소 거래대금 |
| 점수화(100점 만점) 설정 | STRONG/WEAK 최소 점수 |
| 진입 확인(다음 봉 재돌파) 설정 | 최대 대기 봉수 |
| 손절/익절 설정 | 손절률 1/2, 익절률 1/2 |
| 포지션 리스크 계산 | 계좌금액(지표)/허용 손실률 |
| 신호 표시 on/off (지표 버전) | 각 신호별 표시 여부 |
| 백테스트 전용 설정 (전략 버전) | WEAK 등급 포함 여부 |

`Style` 탭에서는 이동평균선/손절익절선 색상과 라벨 표시 여부를 추가로 조정할 수 있습니다.

## 3. 실제 매수 전 확인 체크리스트

- [ ] 시장 지수(벤치마크)가 20일선 위인가
- [ ] 종목이 20일, 60일, 120일 정배열인가
- [ ] SETUP 이후 실제로 ENTRY CONFIRM(재돌파)이 발생했는가 — SETUP만 뜬 상태에서 추격 매수하지 않았는가
- [ ] 돌파/재돌파가 확정봉 종가 기준인가 (장중 일시 돌파가 아닌가)
- [ ] 거래량이 20일 평균 대비 증가했는가
- [ ] 거래대금이 최소 기준을 충분히 넘는가(유동성 확보)
- [ ] 현재 매수 후보 점수가 몇 점인지 확인했는가(STRONG/WEAK 등급 구분)
- [ ] 손절선이 명확한가 (손절선 1/2, 구조적 손절선 확인)
- [ ] 진입가 대비 손절폭이 감당 가능한가 (포지션 리스크 테이블 확인)
- [ ] 최근 급등으로 과열된 상태는 아닌가 (OVERHEATED 라벨 유무 확인)
- [ ] 실적, 공시, 악재 뉴스가 없는가 (지표가 커버하지 않는 부분 — 직접 확인 필요)

## 4. 신호가 너무 많을 때 조정할 값 (더 보수적으로)

- `STRONG BUY WATCH 최소 점수`를 80 → 85 이상으로, `WEAK BUY WATCH 최소 점수`를 60 → 65~70으로 상향
- `VCP 세부조건 중 최소 충족 개수`를 3 → 4~5로 상향
- `거래량 증가 배수`를 1.5 → 2.0 이상으로 상향
- `20일선 이격도 제한 %`를 15 → 10 정도로 축소(더 엄격하게 과열 컷)
- `당일 과열 상승률` / `최근 5일 과열 상승률`을 낮춰서 더 쉽게 차단되도록 조정
- `고점 대비 허용 낙폭`을 -15% → -10%로 축소(더 얕은 조정만 후보로 인정)
- `최소 거래대금`을 상향해 유동성 필터를 강화
- `진입 확인 최대 대기 봉수`를 줄여 오래된 SETUP이 뒤늦게 진입으로 확인되지 않도록 축소
- 시장 필터를 켜고, 벤치마크를 더 넓은 지수(예: 코스피 전체)로 설정

## 5. 신호가 너무 늦을 때 조정할 값 (더 민감하게)

- `돌파 기준 기간`을 20 → 10~15일로 축소(더 짧은 박스권 돌파도 인정)
- `거래량 증가 배수`를 1.5 → 1.2~1.3으로 완화
- `VCP 세부조건 중 최소 충족 개수`를 3 → 2로 완화
- `WEAK BUY WATCH 최소 점수`를 60 → 50~55로 완화
- `20일선 이격도 제한 %`를 15 → 20으로 완화(초입 돌파를 과열로 오판하지 않도록)
- `ATR 축소 비교 기간`을 줄여서 더 최근 변동성 변화에 민감하게 반응하도록 조정
- `진입 확인 최대 대기 봉수`를 늘려 눌림 후 재돌파를 더 오래 기다리도록 조정

(위 두 목록은 각 `.pine` 파일 상단 주석에도 동일하게 정리되어 있습니다.)

## 참고 사항

- 이 지표/전략은 매수 후보 필터링 도구이며 투자 자문이 아닙니다. 최종 매수/매도 판단은 사용자 책임입니다.
- 벤치마크 심볼과 종목의 시가총액/유동성 특성에 따라 기본값이 맞지 않을 수 있으니 실제 사용 전 과거 차트에서
  신호 빈도와 품질, 그리고 전략 버전의 백테스트 결과(승률/손익비/MDD)를 충분히 검토하세요.
- 백테스트 결과는 과거 데이터 기준이며 수수료/슬리피지/유동성 가정에 따라 실제 매매 결과와 차이가 있을 수 있습니다.
- `STRONG BUY WATCH 최소 점수`는 항상 `WEAK BUY WATCH 최소 점수` 이상으로 설정하세요. 반대로 설정하면
  WEAK 등급이 나오지 않는 등 의도치 않은 동작이 발생합니다.
- 상장 초기 구간처럼 이동평균/ATR/VCP 계산에 필요한 과거 데이터가 부족한 봉에서는 관련 조건이 자동으로
  미충족(0점)으로 처리되어 점수가 낮게 나올 수 있습니다. 종목별로 최소 200봉 이상의 데이터가 쌓인 이후
  구간에서 신호를 확인하세요.
