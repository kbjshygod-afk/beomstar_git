# 앱 아이콘 — 「마주 보는 말」

| 파일 | 쓰는 곳 |
|---|---|
| `icon-master.svg` | 원본(1024×1024, 꽉 찬 배경). `icon-512`·`icon-192`(둥근 사각, 모서리 투명), `icon-maskable-512`·`apple-touch-icon`(꽉 찬 사각)을 여기서 뽑아요 |
| `small.svg` | 32·48px용 단순화 원본(가는 장식을 덜어냄). `favicon-32.png`·`favicon.svg`를 여기서 뽑아요 |

- 뜻: 말풍선 하나를 세로로 나눠 왼쪽은 검정(나의 말), 오른쪽은 아이보리(새로 배우는 말). 가운데 금빛 쐐기가 아래로 가늘어지다 꼬리 끝 한 점에서 닫혀 '서로 다른 두 말이 통하는 순간'을 뜻하고, 바깥 두 겹 고리는 그 대화를 감싸는 문장(紋章)이에요.
- 색: 깊은 오렌지(#F37021 근처, 가운데 #E8641F) · 검정(#0B0B0B) · 아이보리(#F6EFE3) · 금(쐐기 한 곳에만).
- 상표 주의: 명품 브랜드의 '대칭·맞물림·절제' 느낌만 빌렸어요. 다른 브랜드의 로고 형태(맞물린 두 C, 마차, 리본 상자, 가죽 스티치 등)를 넣지 마세요.
- 다시 뽑을 때: Chromium(Playwright)으로 SVG를 각 크기로 그려 PNG로 저장해요. 둥근 사각은 초타원(n=5) 클립. 결과를 반드시 32px까지 눈으로 확인하세요.
- 링크 미리보기(`assets/og-image.png`, 1200×630)도 같은 팔레트예요(아이보리 바탕·오렌지 두 줄 테두리, 제목 Noto Serif KR 900).
- 아이콘을 바꾸면 `language-teacher/manifest.webmanifest`의 아이콘 주소 `?v=` 번호를 올려 주세요(설치된 앱이 새 아이콘을 받게).
