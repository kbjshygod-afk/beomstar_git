# 말하기 채점 사전

앱의 🎤 말하기 연습은 브라우저 음성 인식이 돌려준 글을 목표 문장과 비교해 채점해요.
글자만 비교하면 놓치는 것이 있어서, 언어별 사전을 따로 둬요.

| 파일 | 만드는 도구 | 쓰는 곳 |
|---|---|---|
| `language-teacher/speech-zh.js` | `build-zh.py` (pypinyin) | 중국어: 들린 한자의 병음·성조. 같은 소리의 다른 글자(在/再)는 맞게, 성조가 다르면(买/卖) 틀리게 보고 "3성인데 4성처럼 들렸어요"처럼 알려 줘요 |
| `language-teacher/speech-ja.js` | `build-ja.py` (원본 `ja-spellings.json`) | 일본어: 인식기가 한자로 돌려준 글(私は学生です)을 가나로 되돌려 학습 문장과 글자 단위로 비교해요 |

두 파일은 언어를 열 때 뒤에서 받아요. 못 받으면(오프라인 첫 방문 등) 글자 그대로 비교하고,
일본어는 사전에 없는 한자가 들리면 "직접 확인"으로 넘어가요.

## 다시 만들기

```bash
pip install pypinyin            # 중국어
python3 tools/speech/build-zh.py
python3 tools/speech/build-ja.py # 일본어(추가 설치 없음)
node tools/stamp-data-ver.mjs    # DATA_VER 갱신(사전 파일도 해시에 들어가요)
```

- 일본어 학습 데이터(`data-ja.js`)에 말하기 문장(단어·핵심 문장·대화)을 새로 넣었으면, `ja-spellings.json`에 그 문장의 한자 표기와
  한자 덩어리 읽기를 추가하세요. `build-ja.py`가 원본에 빠진 문장을 알려 주고, 읽기를 바꿔 끼웠을 때 학습 문장과 같은지 검사해요.
- 중국어 사전은 자주 쓰는 한자(GB2312 1급 3,755자)와 학습 데이터·이야기에 나오는 한자를 모두 담아요. 데이터를 고친 뒤 다시 실행하면 돼요.
  글자의 다른 소리(py2)는 **실제로 쓰이는 것만** 넣어요(pypinyin 구 사전에서 그 소리로 읽히는 낱말이 5개 이상·4% 이상).
  옛·희귀 독음(吃 qī, 大 tài, 见 xiàn)을 넣으면 인식기가 적은 다른 글자가 같은 소리로 통과해 버려요(七 ← 吃).
- 일본어 사전에는 학습 문장 표기 말고도 초보가 자주 말할 한자 낱말(犬·病院·大学生·足す 등)을 `build-ja.py`의 `EXTRA`에 넣어요.
  사전에 없는 한자가 들리면 "직접 확인"으로 넘어가 틀린 곳을 짚지 못하기 때문이에요.
- 띄어쓰기 없이 적힌 긴 일본어 문장은 `ja-spacing.json`에 채점용 띄어쓰기를 넣어요(화면·녹음은 원래 글 그대로).
  덩어리 끝 조사(は·が·を…)는 긴 문장에서 하나쯤 빠져도 봐주는데, 띄어쓰기가 없으면 조사 자리를 알 수 없어서예요.

## 채점 규칙(요약, 코드는 `index.html`의 `scoreSpeech`)

- 단위: 영어·스페인어·프랑스어는 단어, 중국어는 글자, 일본어는 가나.
- 편집 거리로 맞춰 보고 바뀜·빠짐·더함의 개수를 틀린 곳으로 셈. 점수 = (단위 수 − 틀린 곳) ÷ 단위 수.
- 통과: 틀린 곳이 허용 개수 이하이고, 부정어(not·no·不·没·pas·ません…)와 숫자가 틀리지 않았을 때.
  허용 개수는 짧은 문장 0개, 긴 문장 1~2개(영·서·불 8단어↑ 1, 16↑ 2 / 중국어 10글자↑ 1 / 일본어 가나 12↑ 1).
- 인식기의 1순위 결과만 써요(다른 후보 중 정답에 가까운 것을 고르면 틀린 발음도 맞게 보여서).
- 스페인어는 강세 표시를 남겨 비교해요(estudio 공부해요 ≠ estudió 공부했어요). 강세만 다르고 소리가 같은 말(que/qué 등)과 문장 가운데 이름은 같게 봐요.
- 중국어 3성 연속 변조(앞 3성 → 2성)는 한 말토막 안에서만 봐줘요(你好！我…의 好는 3성 그대로).
- 틀린 곳마다 정답 → 들린 말, 읽기(병음·한글), 발음 요령을 보여 주고 둘 다 들어 볼 수 있어요.
