# R&D AI팀 — 설계와 실행 계획 (2026-10-26 확정)

업무 에이전트(`poll.sh`·`office.py`)를 키워 R&D 업무를 나눠 맡는 AI 직원 팀을 만든다. 새 플랫폼은 쓰지 않고, 지금의 안전장치(읽기 전용 실행 · 제안만 · 승인 해시가 일치할 때만 실행 · 전체 정지)를 그대로 쓴다.

**v1 DoD (2027-02-05 판정)**: AI 직원 8명 + 사무보조가 4주 연속 일정대로 돌고, 지어낸 수치·날짜 0건, 채택률 70% 이상, 무단 발송·원본 수정 0건, 추적 업무 5종(요청 정리·공지·원가 검산·게이트 점검·주간 보고) 시간이 기준선보다 40% 줄어든다.

## 원칙
1. 흐름은 코드가 정하고 AI는 자기 책상 안에서만 판단한다. 직원끼리는 코드가 검증한 JSON 작업지시서로만 일을 넘긴다(최대 2단계).
2. 직원은 읽기 전용, 제안만 한다. 실행은 사무보조가 승인된 건 중 되돌릴 수 있는 것만. 발송·원본 수정·발주·가격 변경은 사람이 한다.
3. 원본은 하나: 원가 = MASTER, 일정 = 시즌 워크플로우, 레시피 = 매장 레시피 xlsx. AI는 Drive `★김범준/00_현재진행/R&D_AI팀_new` 폴더에만 쓴다.
4. 만드는 직원과 검사하는 직원을 나눈다. 품질·규제는 지적만 한다.
5. 직원은 숫자로 자리를 증명한다. 그림자 1주 → 승격, 채택률 50% 미만 2주면 합치거나 끈다.
6. 공개 저장소다. 새 직원부터 파일·폴더 ID, 담당자 이름, 메뉴·원가 내용은 `config.env`·`state/`에 둔다.

## 직원 채용 절차 (직원당 2주)
1. D1 역할 카드(지시문·도구 허용목록·제안 종류) + 골든 케이스 5건(팀장이 과거 완성본 선정)

3. D3~7 그림자 운영(info만), 팀장 하루 5분 확인
4. 2주차 판정: 골든 5건 중 4건 이상, 지어낸 값 0 → 승격
